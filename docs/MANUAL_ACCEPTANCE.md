# 實機操作驗收

這份清單補足自動測試未涵蓋的實際瀏覽器、觸控及使用感受。目前尚未完成實機簽核；未勾選不代表已知故障。各項只在合成服務執行，不輸入或匯出真實技能、提示詞及筆記。

## 準備與紀錄

依 [測試指南](TESTING.md) 啟動獨立合成 fixture，確認測試標記及連接埠，避免使用正在管理真實資料的面板。Windows 啟動器的預設瀏覽器流程須另用隔離副本、合成 home 與獨立連接埠驗收；自動測試以不開瀏覽器的模式執行，不能由其成功推定實際瀏覽器已開啟。

紀錄日期（台灣時間，UTC+8）、提交 SHA、Windows／瀏覽器版本、螢幕縮放、輸入裝置及每項結果。只記通過、失敗或未測與合成重現步驟；不要收錄本機完整路徑、真實畫面或其他開啟分頁。

## 待驗收清單

| 項目 | 操作與通過條件 | 目前狀態 |
| --- | --- | --- |
| 預設瀏覽器 | 隔離副本啟動後開啟正確 loopback 位址；既有服務、停止及重新啟動結果清楚，未接管其他 checkout 或其他服務 | 未測 |
| 桌面捲動 | 長清單與長詳情分別捲動；滑鼠滾輪、觸控板連續操作可到達底部，搜尋與選取後仍可操作。記錄卡頓發生位置及操作，不直接歸因於電腦 | 未測 |
| 字級與縮放 | 標準／較大／特大、Windows 常用縮放與瀏覽器 200% 縮放下，操作按鈕與內容可到達，文字不被永久裁切 | 未測 |
| 側欄與鍵盤 | 收合後能重開；Tab 順序及焦點可見，搜尋、切頁、儲存與取消可操作，彈窗關閉後焦點合理返回 | 未測 |
| 草稿與提示詞 | 合成長筆記及多行提示詞在切換、取消、儲存、重新載入與多視窗衝突時結果符合手冊；失敗時保留草稿且不顯示成功 | 未測 |
| 實際觸控環境 | 真實觸控裝置檢查自然捲動、輸入鍵盤遮擋及返回。需要網路連線的手機不直接連線到本機服務，不放寬 loopback；須先準備經授權的裝置內隔離測試環境，否則維持未測 | 未測 |
| 其他瀏覽器 | 若將宣稱 Safari／WebKit 支援，先在相應環境驗收；Chromium／Firefox 自動案例不能代替此項 | 未測 |

## 結案條件

各項填入實際版本與結果。未取得的裝置／瀏覽器保留未測，文件只宣稱已驗證範圍；發現問題先記錄最小合成重現，再決定修正及適用回歸。沒有實測資料時，不以「應該正常」結案，也不為驗收而將本機管理服務暴露到區域網路或網際網路。
