# Skillpane 操作手冊

本手冊適用 0.3 系列。Skillpane 用來理解及整理磁碟上的技能；不會替你安裝、刪除、停用或修改技能。

## 1. 安裝與啟停

取得 repository 後進入專案根目錄，以目前仍受安全支援的 Python 執行：

```sh
python -m skillpane
```

瀏覽器開啟 `http://127.0.0.1:8766/`。若 `python` 不是有效指令，可依環境使用 `python3` 或 Windows 的 `py`。請勿使用系統管理員／root 權限。

Windows 可雙擊 `Open-Skillpane.cmd`。`Start.ps1 -NoBrowser` 啟動背景服務但不開頁面；`Stop.ps1` 只停止啟動器記錄且身分驗證符合的 8766 程序。手動啟動的前景程序請用 Ctrl+C 結束。

```sh
python -m skillpane --port 8767
```

手動指定其他連接埠時，啟動器仍以 8766 為準。每個 checkout 同時只啟動一個服務，避免多個程序競爭同一份整理資料。關閉瀏覽器分頁不等於停止背景服務。

## 2. 第一次開啟與數量

預設進入「我的技能」。掃描的是目前使用者 home 下的四個位置：

| 位置 | 用途 |
| --- | --- |
| `~/.agents/skills` | 個人技能本體 |
| `~/.codex/skills` | Codex 管理內容與系統技能 |
| `~/.claude/skills` | Claude 技能及同步內容 |
| `~/.codex/plugins/cache` | 外掛磁碟快取 |

「掃描範圍」可查看實際範圍。目前不掃描各專案的技能，也不判定當前對話實際載入了哪些技能。junction／symlink 指向同一實體時合併計算；外掛多個版本會收合。磁碟數量不等於目前能呼叫的數量。

新增、搬移或改動技能後按「重新掃描」。清單中的修改時間是檔案修改時間，不是使用時間。

## 3. 搜尋、篩選與收藏

- 使用搜尋欄或 Ctrl+K，輸入名稱、用途、分類、標籤、加入原因、已儲存筆記或常用提示詞。
- 點分類篩選，再以名稱或修改時間排序。
- 點技能右上角星號加入／移除收藏。
- 「待整理」彙整需要檢查或自行標記的項目；它不是可直接刪除的清單。

桌面列表與右側內容可各自捲動；手機改為整頁自然捲動。標題左側按鈕可收合／展開側邊欄。右上齒輪開啟偏好設定，可選主題與標準、較大、特大字級。這些偏好保存在此瀏覽器的 localStorage，不包含在整理資料備份中。

## 4. 理解技能與呼叫方式

「使用指南」提供用途、CLI 呼叫參考及面板示範。「原始內容」顯示純文字 SKILL.md；「來源與設定」顯示原始名稱、描述、檔案位置與宣告證據。

中文名稱旁的來源標記會區分「Skillpane 中文別名」與「我的自訂名稱」。範例由面板補充，不代表技能作者原文。

自動選用分為明確設定、工具預設與無法判讀。Codex／Claude 的宣告不同是設定差異，不能據此認定有錯。CLI 參考格式不代表桌面版、專案或當前對話一定可用；外掛命名空間未知時，請在對應工具的技能選擇器確認。

## 5. 保存個人整理

在使用指南中編輯筆記及整理標記；按「編輯整理資訊」可設定名稱、摘要、分類、標籤。進階欄位包含加入原因、來源網址、工作範圍及是否修改檔案。

「我的整理」是使用筆記，不會自動變成「試著這樣說」的示範，也不會新增常用提示詞。

### 常用提示詞

1. 在技能的「使用指南」找到「常用提示詞」，按「新增提示詞」。
2. 填寫名稱及內容後儲存；內容支援多行。也可按示範旁的「另存為我的提示詞」，再自行修改。
3. 已儲存項目可一鍵複製、編輯，或確認移除。複製後貼到實際使用的工具送出；面板不會執行提示詞。

每個技能最多 20 筆，名稱最多 80 字、內容最多 4,000 字。`{{環境}}` 等文字只是方便你替換的記號，不會自動代入。提示詞可被搜尋，並隨整理資料備份、匯入及重新關聯。

關閉編輯器會保留目前頁面的草稿；「放棄草稿」才還原。重新整理或關閉頁面前請先儲存。其他視窗已改動同一技能的提示詞時，儲存會停止並保留草稿；先複製自己的內容，關閉再開啟編輯器以讀取新版本，確認後重新編輯。

這些欄位是個人紀錄，沒有自動查證來源。來源網址只允許不含帳密或已知憑證查詢參數的 http／https；這不等於網址已經過惡意網站檢查。

按儲存後才寫入本機。切換技能或關閉編輯面板會保留草稿，但草稿只存在當前頁面記憶體，重新整理／關閉頁面可能遺失；請依離頁提醒先儲存。資料匯入及重新關聯要求先儲存或還原草稿。

「恢復原文」改回原始名稱與描述；「面板預設」改回面板提供的預設顯示。兩者均不改動技能原檔。整理標記中的封存意圖只是本機標記，不會停用或搬移技能。

## 6. 比較相近技能

「重疊檢查」將同名與內容完全相同分開呈現；「同分類工具」僅表示分類相同。按「比較」或群組內比較按鈕，選擇兩個技能。

比較面板提供用途、個人分工、是否改檔、宣告、來源與原文差異。選擇保留兩者、考慮合併或已檢查，填入理由並儲存。這只是整理結論，不會自動合併技能。內容變更並重新掃描後會提示重新檢查；過長差異會截短，完整原文可在技能詳情閱讀。

## 7. 備份、匯入與還原

右上角「資料與備份」可下載已儲存資料。下載格式是 `skillpane-backup` 第 2 版，包含收藏、筆記、常用提示詞、自訂資訊、穩定識別、比較結論與保留設定；未儲存草稿不在備份中。

0.3 可讀取既有第 2 版資料，不會因開啟頁面而改寫筆記。新增提示詞後，資料及備份仍使用第 2 版格式，但必須使用 0.3 以上版本讀取；0.2 不認得新增的提示詞欄位。

偏好設定的「清單匯出」是技能中繼資料 JSON，不能當作個人整理備份還原。兩者都可能含敏感文字，請勿直接上傳。

匯入流程：

1. 選擇不超過 4 MiB 的有效備份。
2. 閱讀每筆對應、現有欄位與備份差異；歧義項目必須手動選擇。
3. 選擇目前欄位優先，或以備份取代。保留現有欄位時，現有空值也視為已存在的欄位。
4. 找不到原技能時選擇保留為未關聯資料，或略過；不要只因同名就認定同一個技能。
5. 確認是否還原保留設定，再套用。套用前會備份目前版本。

預覽最長保留 10 分鐘，只能成功使用一次；目前資料改變時需重新預覽。本機舊版本的「預覽還原」使用相同流程。

備份不是加密檔。請保存在你信任的位置；不要 commit、貼 Issue 或隨其他程式碼分享。

## 8. 技能搬移與未關聯資料

路徑相同時延續穩定識別；搬移後只有來源與內容能唯一對應時才自動接回。其他情況會留下未關聯資料，不丟棄原筆記。

在「資料與備份」選擇目前技能，按「預覽關聯」，檢查原筆記、新資料與比較結論衝突，再決定哪份資料優先。確認後沿用舊穩定識別與首次發現時間，保存歷史關聯紀錄。

首次發現時間從可保存紀錄的版本開始計算；檔案建立時間與 Git 新增提交作者時間各有不同意義，都不能當成安裝日期。

## 9. 備份保留與資料損壞

預設全部保留。選擇最近 10／30／100 份只改變清理候選，不會自動刪除。要清理時先預覽檔名，再勾選永久刪除確認；刪除無法由面板復原。

若本機整理資料損壞，面板會保留原檔、顯示警示並停止一般寫入。可以繼續查看技能，再以有效備份預覽還原／匯入；原檔會先被備份。不要直接刪除 `.data/`。偵測到另一程序改寫檔案時，先停止其他實例、保留資料，再重新啟動。

更多狀況見 [疑難排解](../SUPPORT.md)。
