# 資料與隱私

Skillpane 沒有內建遙測、分析 SDK、雲端同步、更新檢查或第三方 CDN。前端只向同源本機 API 取資料；來源網址連結由使用者主動點擊後，瀏覽器才會前往該網站。

來源時間可呼叫本機 Git 查詢歷史，停用 fsmonitor、外部差異工具、textconv、互動提示與 lazy fetch；不是向 GitHub 查詢使用紀錄。瀏覽器擴充功能、作業系統及外部工具本身的資料行為不在本專案控制範圍。

| 資料 | 位置與處理 |
| --- | --- |
| SKILL.md、工具宣告 | 從使用者層級技能目錄讀取；不修改、不執行 |
| 技能清單與原文 | 存在服務記憶體，透過本機 API 供頁面顯示 |
| 個人整理、穩定識別及路徑提示 | 專案 `.data/annotations.json` |
| 本機舊版本備份 | `.data/backups/`，可能包含原本的路徑提示及個人筆記 |
| 執行紀錄、啟動程序資訊 | `.runtime/`，由啟動器產生 |
| 主題 | 此網站來源下的瀏覽器 localStorage |
| 尚未儲存草稿 | 當前頁面記憶體，沒有持久化保證 |

`.data/`、`.runtime/` 與環境檔預設由 Git 忽略。忽略規則不會移除已被追蹤的檔案，也不能取代完整歷史掃描；強制 `git add -f` 仍可能加入它們。

## 匯出不是匿名化

「清單匯出」排除技能全文與結構化來源路徑欄位，但保留名稱、描述、分類、宣告等中繼資料。描述本身可能含路徑、客戶資訊或內部網址。

「整理資料備份」排除技能全文、結構化本機路徑與路徑產生的舊識別，但包含筆記、自訂文字、來源網址與比較理由。這些文字可能被你填入機密。沒有任何匯出會可靠地清除任意文字內的秘密。

不要把這兩種檔案視為可直接公開的報告。分享前應逐項檢查內容，盡量改用獨立的合成資料重現問題。檔案沒有加密，應由作業系統帳號、磁碟加密及可信任備份位置保護。

## 檔案權限與本機存取

POSIX 系統寫入時將資料目錄限制為 `0700`，新整理檔與備份為 `0600`；既有資料目錄中的內容由父目錄權限保護。Windows 沿用使用者資料夾／專案的 NTFS ACL，不會主動建立或修改 ACL。不要把 checkout 放在其他人可讀取的共用目錄。

服務沒有登入機制，本機其他程式可能存取 API。請勿提供遠端存取、共用系統帳號，或將服務連接埠轉送到網路。完整安全邊界見 [SECURITY.md](../SECURITY.md)。
