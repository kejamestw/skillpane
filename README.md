# Skillpane

[English](README.en.md) · [操作手冊](docs/USER_GUIDE.md) · [疑難排解](SUPPORT.md) · [安全政策](SECURITY.md) · [更新紀錄](CHANGELOG.md)

繁體中文優先的本機 Agent Skills 技能庫。理解每個技能的用途與呼叫方式，把個人技能、工具管理內容與外掛快取分開整理。

以 Apple 介面設計的層次、排版與互動原則規劃，使用系統字型、側欄／列表／詳情三欄結構、深淺主題、鍵盤搜尋與減少動態效果支援。

## 開始使用

建議使用仍在官方安全支援期內的 Python 3.11 以上版本；專案不需第三方 Python／JavaScript 執行相依套件，也不需要 Node 建置。目前是早期版本，主要介面為繁體中文，尚無語言切換。

```sh
git clone https://github.com/kejamestw/skillpane.git
cd skillpane
```

Repository 尚為私人時需要帳號存取權；不要將 token 放進 clone 網址。

```sh
python -m skillpane
```

開啟 <http://127.0.0.1:8766>。連接埠可用 `--port` 指定。

Windows 可雙擊 `Open-Skillpane.cmd`。啟動器優先使用 `SKILLPANE_PYTHON` 指定的 Python、Codex 內附 Python，再尋找 PATH 上的 Python；使用 `Start.ps1 -NoBrowser` 可只啟動服務。停止服務執行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Stop.ps1`。

## 功能

- 預設瀏覽個人技能，另列 Claude 同步、系統內建與外掛快取。
- 依實體路徑合併 junction／symlink 別名；外掛相同技能的不同快取版本收合顯示。
- 搜尋名稱、用途、分類與本機筆記；支援名稱／修改時間排序。
- 已知的個人設計技能提供中文別名與摘要，標明由 Skillpane 補充；原始名稱與完整描述可在來源頁查看。範例標為面板示範，不改寫 SKILL.md。
- 顯示 Codex CLI／Claude Code 參考格式；外掛命名空間未確認時引導使用技能選擇器，不猜指令。
- 自動選用欄位區分明確設定、工具預設與無法判讀，提供來源檔與行號。工具間的設定差異列為提示，不直接列入待整理。
- 同名與完全相同內容列為重疊候選；同分類工具另外呈現，不視為重複或淘汰建議。
- 搜尋、分類與整理操作同步更新右側選取；沒有結果時清空詳情。未儲存筆記在切換技能、分類與重新掃描時保留，還原原值後解除離頁提醒。
- 收藏、筆記與整理標記另存本機 `.data/annotations.json`，備份使用唯一檔名。
- 自訂名稱、摘要、分類、標籤、加入原因與來源網址；可恢復原文或面板預設顯示。工作範圍與是否改檔採用個人紀錄，未記錄時維持未知。
- 分別顯示首次被 Skillpane 發現、本機檔案建立與可讀取的 Git 最早新增提交作者時間，不推定安裝日期。
- 使用獨立的穩定識別保存整理資料；路徑不變時延續識別，搬移後只有來源與內容都能唯一對應時才自動接回。歧義與未找到原技能的資料保留在「資料與備份」供人工重新關聯。
- 並排比較兩個技能的用途、個人工作範圍、是否改檔、呼叫宣告、來源與純文字原文差異。可保存整理結論與理由；內容變更後提示重新檢查。
- 原始內容以純文字顯示；不渲染 skill 中的 HTML、不執行 scripts。
- 匯出技能中繼資料，不包含技能全文與來源路徑。

## 安全與資料範圍

技能原始檔維持唯讀；目前不提供新增、修改、刪除或封存技能。收藏、筆記、標記、自訂資訊、穩定識別與比較結論只會寫入本機 `.data/`。`.data/`、`.runtime/`、環境檔、測試產物皆排除於 Git；不將真實 skills 或個人掃描清單放入此 repository。

HTTP 服務僅監聽 `127.0.0.1`，檢查 Host、Origin 與 Fetch Metadata。整理資料寫入另要求同源 JSON 與自訂 header，不提供 CORS。靜態資源使用允許清單；內容 API 只接受掃描過的技能 ID。單一 skill 大小上限為 2 MiB。

這是本機個人工具，沒有登入系統；同一位作業系統使用者的其他程式仍能讀取本機服務。不要將服務對外轉送。

公開原始碼與將服務部署到網路是不同情境。此服務以 Python `http.server` 為基礎，僅設計供本機個人使用，不支援共享主機、公開網路、反向代理或 tunnel。安全邊界與已知限制見 [安全政策](SECURITY.md)；匯出檔案仍可能包含名稱、描述或個人筆記中的敏感內容，詳見 [資料隱私](docs/PRIVACY.md)。

### 數量的定義

「我的技能」計算個人技能本體；「內建與外掛」包含工具管理內容。外掛顯示版本排序較新的磁碟快取，無法據此確認當前對話實際啟用的版本。不同來源或外掛的同名技能不會直接合併。

目前沒有可靠的使用次數、最近呼叫時間或自動淘汰判定；修改時間不視為使用時間。

### 整理資料、備份與還原（0.2）

第 2 版整理資料在同一份 `.data/annotations.json` 保存穩定識別、收藏筆記、自訂欄位、首次發現紀錄、比較結論及備份設定。初次升級時會先備份原始第 1 版檔案，保留既有整理內容，再對應目前的技能；不改動技能本體。首次發現時間從可保存此紀錄的版本開始計算。

右上角「資料與備份」提供：

- **下載整理資料備份**：格式為 `skillpane-backup`、版本 `2`，包含已儲存的個人整理與比較結論；不含技能原文、本機路徑與路徑產生的舊識別。檔案含個人筆記，請妥善保存。
- **匯入／本機版本還原**：先驗證格式、技能對應及衝突，不直接套用。可保留目前欄位、以備份取代、略過，或保留為未關聯資料；套用前會另存目前版本。預覽期間資料若改變，須重新預覽，避免覆蓋剛儲存的內容。
- **重新關聯**：選擇未關聯資料與目前技能，先看筆記及比較結論衝突，決定新舊資料何者優先。沿用原穩定識別與首次發現時間，保留歷史關聯紀錄，不直接把同名技能合併。
- **保留策略**：預設全部保留。設定最近 10／30／100 份只影響清理預覽；不自動刪除。清理必須先列出檔案清單，再勾選永久刪除確認。變更期間有其他寫入或備份被修改時，原預覽失效。

整理資料及匯入檔案上限為 4 MiB。匯入的來源網址限不含帳密與憑證參數的 http／https。格式錯誤不套用；本機檔案損壞時保留原檔，仍可查閱技能，並從面板預覽還原或匯入。若偵測另一程序修改資料檔，停止寫入並要求重新啟動，不覆蓋外部變更。

「技能清單匯出」仍保留在偏好設定，與可還原個人整理的備份格式分開；清單 JSON 不能當成整理資料備份匯入。

右上角「掃描範圍」列出四個使用者層級目錄；目前不掃描各專案的 `.agents/skills`，也不宣稱確認工具或目前對話的實際啟用狀態。

### 設定判讀範圍

`skillpane/metadata.py` 是不執行內容的 YAML 欄位判讀器，支援區塊對應表、常見純量、引號、註解與多行描述；不是通用 YAML parser 或完整文件驗證器。相關欄位出現不支援的寫法、重複定義、不合法布林值或縮排問題時，顯示「無法判讀」。只有可確認欄位未設定時才採用工具預設，不將字串 `"false"` 誤當布林值。

Codex 判讀 `agents/openai.yaml` 的 `policy.allow_implicit_invocation`；Claude Code 判讀 frontmatter 的 `disable-model-invocation`。宣告與技能文字敘述的使用意圖分開呈現；工具載入、專案設定與對話可用性仍需在對應工具確認。

## 開發與驗證

```sh
python -m unittest discover -s tests -v
node --check web/app.js
node --check web/management.js
```

Windows junction 測試需允許建立工作目錄內的 junction；其他平台會略過該項。測試只使用 `.runtime/test-runs/` 內的假資料。Node 僅用於可選的語法檢查。

GitHub Actions 設定包含 Windows／Linux、Python 3.11／3.13 的單元與安全測試、JavaScript 語法檢查、Git 私有路徑檢查及全歷史 Gitleaks 掃描。這些自動檢查須推送後才會執行；流程與公開前檢查方式見 [開發指南](docs/DEVELOPMENT.md)。

瀏覽器回歸驗證使用獨立服務，避免操作真實筆記：

```sh
python -B tests/browser_fixture.py --port 8779
node --check tests/browser-regression.js
```

開啟 `http://127.0.0.1:8779/`，將 `tests/browser-regression.js` 的函式貼入瀏覽器開發者工具，再執行 `await runSkillpaneRegression()`。腳本先檢查測試服務標記，在正式服務會直接拒絕執行。假資料保留於 `.runtime/browser-fixture-*`，不讀取真實 home 或筆記。

覆蓋搜尋／分類與詳情同步、筆記草稿與儲存、收藏與整理清單進出、原始內容純文字、來源標示、重疊分類、長列表與詳情捲動、主題和技能指紋不變。建議分別驗證 1280×720、1024×480 與 390×844；手機版採整頁捲動，桌面版採列表與詳情各自捲動。

第二批管理操作使用同一個獨立假資料服務：貼入 `tests/browser-management.js` 後執行 `await runManagementRegression()`。驗證自訂欄位、草稿、匯入預覽與覆蓋、未關聯資料接回、本機還原預覽、手動保留策略與比較結論。瀏覽器測試不執行永久清理；後端測試以 mock 確認刪除目標，避免在開發驗證時真的刪除備份。
